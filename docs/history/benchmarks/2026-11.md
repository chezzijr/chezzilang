## A C call takes its permit steps from the wait table; the sysmon watcher (2026-11-02)

The `extern` call path changed: `Vm::wait_call` takes the `Extern` row of `block::wait_steps`, a
watch-slot stamp and swap (`vm/sysmon.rs`), and the halt read at the return. Release binaries, base
`a3d2c2eb` vs the branch, each in its own `CARGO_TARGET_DIR`. `extern_abs` is new
(`benches/sched/extern_abs.chz`: 1e5 `labs` calls in one `spawn`); it was timed with 3 alternating
blocks of `perf stat -r 10` per binary (30 runs per side), because `hyperfine` runs one binary
after the other and this box drifts by about 5% between sessions. The other cells: `hyperfine -N -w 3
-r 15`.

| bench | T | base | branch | branch/base |
|---|---|---|---|---|
| extern_abs | 1 | 97.8 ms | 110.4 ms | 1.128 |
| extern_abs | 2 | 103.6 ms | 109.1 ms | 1.053 |
| extern_abs | 4 | 99.8 ms | 113.3 ms | 1.135 |
| rendezvous_pingpong | 1 | 2.967 s | 2.870 s | 0.97 |
| send_one_channel | 1 | 0.758 s | 0.734 s | 0.97 |
| body_and_spawn | 2 | 2.966 s | 3.014 s | 1.02 |

Owner decision (2026-11-02): the `extern_abs` cost is accepted for that cell only (5-14% measured
over three sessions of the same method; the box drifts about 5% between sessions); every other cell keeps the 10% gate. A C call costs 4393 instructions on base and about 4800 on the branch. Measured parts
(50 runs per side, before the hint gate): the halt read cost 4-9% (three cell locks in
`QuiesceState::run_halt`), the table step and the watcher 5-9%. The halt read now reads the
run-wide rung behind `run_halt_hint`. Two designs were dropped: a demote on each call (543 ms against
115 ms, `2026-10.md`), and a watcher that slept between calls (a `SeqCst` stamp and a wake check on
each call; a destructor thread-local per call).
